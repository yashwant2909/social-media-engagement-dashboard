# 📊 AI-Powered Social Media Engagement Dashboard

## 🚀 Project Overview
This project analyzes YouTube engagement data using Python, YouTube API, Pandas, and Power BI.

The dashboard helps analyze:
- Audience engagement
- Best upload days
- Best posting times
- Top-performing content
- Engagement trends

---

## 🛠 Technologies Used
- Python
- Pandas
- YouTube Data API v3
- Power BI
- Git & GitHub

---

## 📈 Features
✅ YouTube API Integration  
✅ Engagement Rate Analysis  
✅ Best Upload Day Analysis  
✅ Best Posting Time Analysis  
✅ KPI Metrics Dashboard  
✅ Interactive Power BI Dashboard
